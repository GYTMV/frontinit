# 🌷 Florería Garden

Sitio web desarrollado en HTML5 y CSS3 para una florería, con diseño responsive, catálogo de productos, video promocional y formulario de contacto integrado con Formspree.

## 📋 Características

- Menú de navegación con enlaces internos.
- Imagen principal centrada en el encabezado.
- Catálogo de flores con tarjetas de productos.
- Video promocional embebido.
- Sección "Quiénes Somos".
- Formulario de contacto funcional mediante Formspree.
- Información de contacto.
- Diseño adaptable a dispositivos móviles.
- Desplazamiento suave entre secciones.

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- Google Fonts (Roboto)
- Formspree

## 🚀 Instalación

1. Descargar o clonar el proyecto.
2. Verificar que las carpetas `IMAGE` y `videos` existan.
3. Abrir `index.html` en el navegador o ejecutar mediante Live Server.

## 📧 Configuración del formulario

El formulario utiliza Formspree para el envío de mensajes.

Reemplazar el atributo `action` por el endpoint generado en Formspree:

```html
https://formspree.io/f/TU_ID
```

## 🎨 Secciones del sitio

### Inicio
Encabezado con imagen principal y nombre de la florería.

### Productos
Muestra tres productos destacados:

- Flor Amarilla
- Flor Roja
- Tulipán

### Video
Video promocional de los productos florales.

### Quiénes Somos
Presentación de la empresa y sus objetivos.

### Contacto
Formulario para consultas y datos de contacto de la empresa.
